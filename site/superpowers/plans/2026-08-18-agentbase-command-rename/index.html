    AgentBase CLI Command Rename Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Rename grn agentbase identity → access, identity workload → access agent-id, and grn agentbase catalog → marketplace across the CLI code, docs, and the integration-test repo; drop the Backend-service column and scrub internal agent-core-* / Go package-path names from user-facing docs.

    Architecture: A mechanical rename with no API or profile-key changes. CLI command Use strings change; help prose keeps the resource noun "agent identity" (only the path/verb renames). Docs files are git mv'd to match new paths, with in-file H1/command-path lines updated via scripted edits. The integration-test repo's matrix Cmd strings and service-filter keys are renamed to match. Two repos land together (integration-test builds the CLI from a sibling path).

    Tech Stack: Go + cobra (go/cmd/agentbase/), MkDocs (docs/ + mkdocs.yml), a Go integration-test harness (harness/matrix.go).

    Global Constraints

    • Hard cut, no aliases. Old command names stop working; no deprecated/hidden shims.
    • Keep the agent_identity profile key and cfg.AgentIdentity field. No profile migration.
    • Noun policy: keep "agent identity" in help prose and runtime output; rename only Use strings and command-path references.
    • Top-level grn agentbase and the agentbase Go build tag are NOT renamed. API endpoints (/api/v1/agent-identities, /flavors, /openclaws) are NOT renamed.
    • Internal Go package internal/agentbase/identity stays named identity (not user-facing; rename is pure import-path churn). Only the cmd/agentbase/identity.go file renames to access.go.
    • Spec/plan location: docs/superpowers/ is local-only and git-ignored — do NOT commit the spec or this plan.
    • Conventional Commits: the CLI PR title is feat!: (breaking) so release-please bumps major. Integration-test PR title is feat: or chore:.
    • Working dir notes: the CLI lives under greennode-cli/go/ (so cmd/ = go/cmd/). The integration-test repo is a sibling: ../greennode-agentbase-integration-test.
    • Doc rule (CLAUDE.md): after renaming/moving commands, the doc pages, index.md tables, and mkdocs.yml nav must all be updated in the same change.

        if _, _, err := agentIDCmd.Find([]string{want}); err != nil {
