# unregister-fleet

Remove a cluster's fleet association. Confirmation or `--force` is required.

Source: [VKS API](https://docs.api.greennode.ai/service-docs/vks-api.html), `PUT /v1/clusters/{clusterId}/unregister-fleet`.

```bash
grn vks unregister-fleet --cluster-id <cluster-id> [--dry-run] [--force]
```
