# get-upgrade-insights

Get a cluster's upgrade insights. Pagination is 0-based and returns one page.

Source: [VKS API](https://docs.api.greennode.ai/service-docs/vks-api.html), `GET /v1/clusters/{clusterId}/upgrade-insight`.

```bash
grn vks get-upgrade-insights --cluster-id <cluster-id> [--page <page>] [--page-size <size>]
```
