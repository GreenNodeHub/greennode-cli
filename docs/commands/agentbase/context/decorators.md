# context decorators

Show SDK decorator reference.

## Description

Display the GreenNode AgentBase SDK decorators and their purpose.

## Synopsis

```text
grn agentbase context decorators
```

## Options

This command takes no command-specific options.

## Global options

All `grn agentbase` commands accept:

- `-o, --output` — Output format: "table", "json", or "id" (default `table`)
- `-i, --interactive` — Prompt for missing inputs instead of requiring flags
- The shared `grn` global options: `--profile`, `--region`, `--query`, `--endpoint-url`, `--debug`

## Examples

Show the SDK decorator reference:

```bash
grn agentbase context decorators
```
