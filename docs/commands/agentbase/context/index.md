# context

Inspect the active agentbase environment and platform reference tables.

```bash
grn agentbase context <command> [options]
```

## Available commands

| Command | Description |
|---------|-------------|
| [current](current.md) | Show the active environment and resolved endpoints |
| [headers](headers.md) | Show platform request headers reference |
| [decorators](decorators.md) | Show SDK decorator reference |
